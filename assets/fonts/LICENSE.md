# Splash fonts

Both files are glyph subsets made for the Desktop splash (ui/src/components/Splash.tsx): only the characters the splash prints are in them.

| File | Family | Source |
| --- | --- | --- |
| archivo-900-subset.woff2 | Archivo, weight 900 | Google Fonts (fonts.google.com/specimen/Archivo); upstream https://github.com/Omnibus-Type/Archivo |
| jetbrains-mono-500-subset.woff2 | JetBrains Mono, weight 500 | Google Fonts (fonts.google.com/specimen/JetBrains+Mono); upstream https://github.com/JetBrains/JetBrainsMono |

Both families are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). The subsets are derived works under the same license; the reserved font names stay with their authors. The fonts are not sold on their own.

Glyphs: Archivo is "You ask once."; JetBrains Mono is A-Z, a-z, 0-9, space, full stop, hyphen, plus and the middle dot (the eyebrow in either case, and the footer "crew.forgecoreai.com . v<version>"). Fetched from Google Fonts with `text=` set to that glyph set and a Chrome user agent; 5128 bytes.
